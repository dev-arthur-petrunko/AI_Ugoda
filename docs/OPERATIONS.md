### Режим продакшну (Docker)
- **Тип:** PostgreSQL 16 (контейнер `aiugoda_postgres`)

> **Правило:** ніколи не пишите жорстко задані шляхи до `C:\Users\...` у коді бекенду. У `app/core/database.py` шлях до SQLite розв'язується відносно поточного файлу конфігурації через `pathlib.Path.resolve()`.

## 3. Рівень безпеки (поточний стан)

Проєкт знаходиться на **Фазі 2 (прототип даних)**. Чесний статус:

| Компонент | Статус | Деталі |
|-----------|--------|--------|
| **База даних** | ⚠️ Прототип | SQLite з 5 тестових актів. Потрібна міграція на PostgreSQL |
| **Імпорт актів** | ⚠️ Прототип | Реальний імпорт з zakon.rada.gov.ua не виконаний (мережеві тайм-аути) |
| **Деталі акта / diff** | ❌ Не готово | Немає сторінки «на дату», порівняння редакцій |
| **Повнотекстовий пошук** | ✅ Готово | SearchService з LIKE-пошуком (потрібна заміна на PostgreSQL FTS) |
| **Детектор колізій** | ✅ Готово | 3 типи (HIERARCHY, SAME_LEVEL_NEWER, DEAD_REFERENCE), додано EXPIRING, GHOST_NORM |
| **ІІ / RAG** | ❌ Не готово | Немає chat, векторного пошуку, перевірки цитат |
| **Фронтенд** | ⚠️ Прототип | Next.js App Router, але не запущено через npm/PowerShell проблеми |

Нижче наведено чесний огляд безпеки:

### ✅ Реалізовано
- CORS-мережа (тільки `http://localhost:3000` у розробці)
- SQLAlchemy з параметрованими запитами (захист від SQL-ін'єкцій)
- Жодних твердо заданих паролів у коді (крім `SECRET_KEY=dev-secret-change-me`, який позначений як development)
- Завантажені файли договорів хешуються (`secure_storage_key`), але ще не реалізовано фактичне шифрування вмісту
- Аудитний журнал (`audit_logs`) без запису повного тексту договорів

### ❌ НЕ реалізовано (не робити в продакшні без виправлення)
| Проблема | Де | Статус |
|----------|----|--------|
| `SECRET_KEY=dev-secret-change-me` | `.env` | ⚠️ Змінити перед продакшном |
| `COOKIE_SECURE=false` | `.env` | ⚠️ Куки не зашифровані |
| JWT автентифікація не додана | `app/api/deps.py` (заглушка) | ⚠️ Працює лише як заглушка |
| Немає Rate Limiting | Бекенд | ⚠️ Потрібно додати |
| Немає CSRF захисту | Фронтенд/бекенд | ⚠️ Потрібно додати |
| Немає CSP заголовків | Фронтенд | ⚠️ Потрібно додати |
| Контракти не шифруються в м'якій формі | `apps/api/app/services/` | ⚠️ Заглушка |
| Логи можуть містити метадані документів | `api.err.log` | ⚠️ Не публікувати логи |

### Рекомендація агенту
- Не додавайте нових секретів у `.env` або у код — використовуйте змінні середовища.
- При тестуванні не надсилайте реальні тек스트 договорів через `AI_PROVIDER=groq/openai/anthropic`, якщо ключ не додано (зараз `mock`).
- При пуші в GitHub переконайтеся, що `.env` додано у `.gitignore` (вже додано).

## 4. Як запустити проєкт локально (чекулист для агента)

```powershell
# 1. Перейти в корінь проєкту
cd "C:\Users\Arthur\Desktop\AI Ugoda"

# 2. Переконатися, що .env існує (створити з .env.example, якщо немає)

# 5. Запустити бекенд (uvicorn)

# 6. Перевірити
curl.exe -s http://127.0.0.1:8000/health

# 7. Запустити тести
python -m pytest
```
