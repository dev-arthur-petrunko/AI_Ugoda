## 2. Перевірка офіційного джерела zakon.rada.gov.ua

Отримано з порталу (23.10.2026):

- Головна сторінка 법ової бази доступна: `https://zakon.rada.gov.ua/laws/main/index`.
- Контент ліцензовано **Creative Commons Attribution 4.0 International** (якщо не вказано інше).
- База описується як **інформаційна, не є офіційним друкованим виданням** — потрібно посилання на першіджерело та попередження користувачам.
- Є розділ RSS: `https://zakon.rada.gov.ua/go/rss` — перераховані стрічки (нови надходження, прийняті документи тощо).
- У оточенні сторінки RSS повертають **HTML-обгортку**, а не чистий XML. Чистий RSS-XML ендоポイント **не підтверджено** як стабільний задокументований публічний API.
- Não знайдено недокументованого публічного API — імпорт реалізується як обережне HTTP-отримання сторінок з чіткою позначкою перевірки.

## 3. Рішення (ФАЗА 0)

- Коннектор `apps/api/app/services/connector.py` перевіряє досяжність джерела та записує результат у `source_check` (досяжність, статус, content-type, чи підтверджено RSS-XML, примітка).
- Імпорт у БД не виконується на цьому етапі (скелет `sync_once` повертає підсумок без побічних ефектів).
- Дашборд і всі списки показують **чесний порожній стан** (нулі, без вигаданих статистик).
- Всі сторінки розділів spécifications створені як навіговáveis оболонки.
