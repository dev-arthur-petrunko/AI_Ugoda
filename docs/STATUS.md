### 1.2 Фронтенд (Next.js 16, React 18, TypeScript)

- **14 сторінок** працюють: огляд із 3D-сценою-фоном, пошук із фільтрами, картка акта з 3 вкладками (**Текст / Аналіз / Якість розбору**), AI-юрист, колізії, карта законодавства, моніторинг, зміни, робоче сховище, закладки, звіти, договори, налаштування (вхід/реєстрація), адмінпанель із **«Звітом імпорту»**.
- **Оболонка**: сайдбар 8 пунктів + група «Джерела та тема» (зовнішнє «Верховна Рада» → zakon.rada.gov.ua, перемикач теми), Ctrl+K-палітра на 14 пунктів, чип лічильника в шапці, футер-атрибуція, splash-заставка (миттєво вимикається в Playwright).
- **Тема**: `lib/theme.ts` — localStorage + `.theme-light` + CustomEvent; сцена 3D синхронно перемикає день/ніч.
- **3D-сцена** (three.js 0.187): «Площа Конституції» процедурно; 7 хотспотів із карточками й навігацією; `THREE.Timer`, `PCFShadowMap`, `fitFov` під вузький формат; сцена — фон усього hero-блоку під заголовком (вуаль для читабельності).
