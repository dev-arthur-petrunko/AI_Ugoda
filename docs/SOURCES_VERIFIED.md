## 1. data.rada.gov.ua — API переліку

```
curl.exe -I https://data.rada.gov.ua/ogd/zak/laws/list.json
```

| Параметр | Значення |
|---|---|
| Код відповіді | **200 OK** |
| Content-Type | `application/json` |
| Content-Length | 2058 байт (JSON-каталог набору, не сам перелік) |
| Server | nginx/1.19.0 |
| CORS | `Access-Control-Allow-Origin: *` |
| Кешування | `ETag` + `Last-Modified` (оновлюється ~щохвилини) |
| Обмеження/ліміти | 429/rate-limit не виявлено; `Accept-Ranges: bytes` (підтримка Range) |
| Заголовки | User-Agent бажаний (ввічливість); автентифікація не потрібна |

**Формат відповіді:** JSON-каталог `{id, title, path, item:[{id,path,title}]}` — вказує на піднабори `/ogd/zak/laws/docs/`, `/dict/`, `/proj/`.

## 4. robots.txt і ліміти

`https://data.rada.gov.ua/robots.txt`:
```
User-Agent: *
Disallow: /
```
⚠️ **Розбіжність/обмеження:** data.rada.gov.ua формально закриває `*` від кравлерів, хоча відкриті дані мають відкриту ліцензію (див. §5) і окремі агенти (Googlebot) — дозволені. **Обмеження для нас:** тримати ≤1 запит/с, чесний UA з контактом, використовувати пакетні ZIP/TSV замість тисяч дрібних запитів, кешувати (raw_payload + SHA-256). Рішення щодо повного дотримання `Disallow: /` — на рішенні замовника (зафіксовано в STATUS.md).

## 7. Обмеження (підсумок)

1. `data.rada.gov.ua/robots.txt`: `User-Agent: *` → `Disallow: /` — ввічливий режим обов'язковий (≤1 req/s, UA з контактом, пакетні файли, кеш).
2. Каталожні `list.*` — не перелік актів; реальні дані в `/ogd/zak/laws/data/csv/*` (TSV, windows-1251) та архівах `.zip`.
3. Ліцензія CC BY 4.0 — обов'язкова атрибуція у футері.
4. `zakon.rada.gov.ua/laws/show/{nreg}` — HTML, стабільний ETag/Last-Modified.
5. Немає публічного «one-shot ZIP з усіма повними текстами статей» — повні тексти актів у HTML `zakon.rada.gov.ua` (парсинг структури — S3.5).
