# AI Ugoda — навигатор і детектор небезпеки над законодавством України

Законодавство України — зрозуміле, актуальне та пов'язане. Від офіційного тексту до практичного аналізу.

> **Головне правило проєкту:** ніколи не вигадуємо закон. Кожне твердження = посилання на акт + статтю + дату редакції. Джерела не знайдено — пишемо «не знайдено в базі».

## Поточний стан

Реалізовано **Фазу 0 (аудит)** та початок **Фази 1 (дизайн-система, оболонка, коннектор даних)**:

- **Бекенд:** FastAPI + SQLAlchemy + Alembic (PostgreSQL), версійна схема даних (акти, ревізії, положення, події, посилання, колізії, користувачі, моніторинг, договори, аудит).
- **Фронтенд:** Next.js + Tailwind, дизайн-система «Black · Coffee · Gold», адаптивна навігація, дашборд, сторінки розділів.
- **Інфраструктура:** Docker Compose (PostgreSQL, Redis, API, Web, Worker).
- **Коннектор даних:** data.rada.gov.ua (основний, відкриті дані JSON/CSV/XML) + zakon.rada.gov.ua (запасний).
- **Не реалізовано ще:** реальний імпорт актів, AI/RAG, завантаження договорів, автентифікація JWT, сповіщення.

## Швидкий старт (Docker)

```bash
# 1. Скопіювати змінні середовища
cp .env.example .env
# відредагуйте .env при потребі (SECRET_KEY, AI_PROVIDER тощо)

# 2. Запустити сервіси
docker compose up --build

# 3. Відкрити
# Web:  http://localhost:3000
# API:  http://localhost:8000 (документація /api/v1/docs)
# Health: http://localhost:8000/health
```

Команди:
```bash
docker compose up -d          # у тлі
docker compose logs -f api    # логи бекенду
docker compose down           # зупинка
docker compose exec api alembic upgrade head  # міграції (запускаються автоматично при старті API)
```

## Змінні середовища

Див. `.env.example`. Обов'язково змініть `SECRET_KEY` перед продакшном.

## Джерела даних (перевірені)

Див. `docs/SOURCES_VERIFIED.md`. Основне джерело — `data.rada.gov.ua/ogd/zak/laws/` (відкриті дані ВР). Запасне — `zakon.rada.gov.ua`.

## Обмеження (чесний стан)

- Жодних документів ще не імпортовано (очікується на Фазі 2).
- Жодних вигаданих статистик — дашборд показує нулі з поясненням.
- AI не підключено до реальних даних (`AI_PROVIDER=mock` за замовчуванням).
- Чистий RSS-XML zakon.rada.gov.ua не підтверджено як стабільний публічний API.
